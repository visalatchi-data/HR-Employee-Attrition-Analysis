# HR Employee Attrition & Retention Analysis

## Project Overview
This project analyzes HR data to identify the key factors contributing to employee attrition and provides data-driven recommendations to improve employee retention strategies.

## Project Structure
* **data/**: Contains the cleaned HR dataset (`hr_clean_data.csv`).
* **sql/**: Contains the database schema (`create_table.sql`) and 10+ analytical business queries (`hr_attrition_analysis.sql`).
* **tableau/**: Contains the packaged Tableau workbook (`.twbx`) for visual analytics.
* **dashboard/**: Contains the high-resolution screenshot of the interactive dashboard.

## Key Insights & Analytics Covered
1. Attrition rate by Department and Job Role.
2. Impact of Business Travel and Overtime on Employee Attrition.
3. Correlation between Job Satisfaction, Environment Satisfaction, and Attrition.
4. Age group and Gender-based attrition trends.

## Tech Stack Used
* **Database:** PostgreSQL (pgAdmin 4)
* **Data Visualization:** Tableau Desktop
* **Documentation:** Markdown / GitHub
